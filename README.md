# SmartPrep - Online Learning & Exam Preparation Platform

## Overview

SmartPrep is a web-based learning and exam preparation platform designed to help students improve their academic performance and assist teachers in managing educational content efficiently.

The platform allows students to attempt quizzes, track their progress, and access study materials, while teachers can create quizzes, upload lectures, and manage learning resources.

## Features

### Student Features

* User registration and login
* Attempt online quizzes
* View quiz results and scores
* Track learning progress
* Access study materials and lectures
* Personalized learning experience

### Teacher Features

* Teacher authentication
* Create and manage quizzes
* Upload study materials and lectures
* Monitor student performance
* Manage educational content

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/SmartPrep.git
```

2. Move the project to your web server directory.

3. Create a MySQL database.

4. Import the provided SQL file into MySQL.

5. Update database credentials in the configuration file.

6. Start Apache and MySQL.

7. Open the project in your browser.
